## Setup and Installation

This project uses a Python virtual environment (`venv`). Follow these steps to set it up and run the application.

### 1. Clone the repository
```bash
git clone https://github.com
cd your-repo-name
```

### 2. Create and Activate the Virtual Environment

Choose the command matching your operating system:

* **Windows (Command Prompt):**
  ```cmd
  python -m venv venv
  venv\Scripts\activate
  ```
* **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
* **macOS / Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Install Dependencies
Once the virtual environment is active, install the required packages:
```bash
pip install -r requirements.txt
```

### 4. Run the Application
To launch the program, execute the following command:
```bash
python main.py
```
*(Note: Replace `main.py` with the actual name of your entry script if it is different).*
